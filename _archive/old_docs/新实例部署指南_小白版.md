# 新实例部署指南（小白版）

> 前提：你手上有这 3 个文件
> - `omni_29dof_v260705.zip`（约 7MB，机器人模型+脚本）
> - `IsaacLab.tar.gz`（约 35MB，仿真框架）
> - `TienKung-Lab-main.zip`（约 160MB，训练框架）

---

## 第一步：开通实例

1. AutoDL 控制台 → **创建实例**
2. GPU 选 **RTX 4090**
3. 镜像选 **PyTorch → 2.8.0（或任意版本）→ CUDA 12.x**
4. 系统盘 30GB，数据盘 50GB（默认就行）
5. 点击 **创建** → 等待开机

---

## 第二步：打开 JupyterLab

1. 实例开机后，在实例列表找到你的实例
2. 看到一排快捷工具图标，点击 **JupyterLab**
3. 浏览器会打开一个新页面，左边是文件管理器

---

## 第三步：上传 3 个文件

1. 在 JupyterLab 左边文件管理器中，确认当前路径是 `/root`
2. 点击文件管理器上方的 **上传按钮**（向上箭头图标 ⬆️）
3. 选择这 3 个文件，全部上传：
   - `omni_29dof_v260705.zip`
   - `IsaacLab.tar.gz`
   - `TienKung-Lab-main.zip`
4. 等上传完成（左边能看到这 3 个文件就行）

---

## 第四步：打开终端

1. 在 JupyterLab 页面，点击左上角 **「+」** 号（新建标签页）
2. 在弹出的面板中找到 **「Terminal」**（终端），点击它
3. 会打开一个黑色命令行窗口

---

## 第五步：一键安装（复制粘贴）

在终端里**逐行复制粘贴**以下命令（每行粘贴后按回车）：

```bash
# 把文件移到数据盘
mv /root/omni_29dof_v260705.zip /root/IsaacLab.tar.gz /root/TienKung-Lab-main.zip /root/autodl-tmp/

# 进入数据盘
cd /root/autodl-tmp

# 解压 OMNI 模型包
mkdir -p omni_29dof_v260705
unzip -q omni_29dof_v260705.zip -d omni_29dof_v260705
# 如果解压后里面还套了一层目录，展平它
if [ -d "omni_29dof_v260705/omni_29dof_v260705" ]; then
    mv omni_29dof_v260705/omni_29dof_v260705/* omni_29dof_v260705/
    rmdir omni_29dof_v260705/omni_29dof_v260705
fi

# 运行一键安装脚本（约 30-40 分钟）
cd omni_29dof_v260705
chmod +x setup_tienkung.sh
bash setup_tienkung.sh
```

然后**等它跑完**。中间会看到很多输出，不用管，只要最后出现：

```
============================================
  安装完成！
============================================
```

就是成功了。

> ⚠️ 如果中间 Isaac Sim 下载很慢，脚本会尝试从网上下载（约 10GB）。
> AutoDL 内网一般很快，10-20 分钟能下完。

---

## 第六步：验证环境

安装完后，在同一个终端继续：

```bash
bash verify_env.sh
```

看到大部分 `[✓ 通过]` 就没问题。

---

## 第七步：试跑训练

```bash
# 激活环境
export CONDA_ENVS_PATH="/root/autodl-tmp/conda_envs"
eval "$(conda shell.bash hook)"
conda activate env_isaaclab

# 进入项目
cd /root/autodl-tmp/TienKung-Lab

# 跑 100 步验证（约 5 分钟）
python legged_lab/scripts/train.py --task=omni_walk --headless --num_envs=64 --max_iterations=100
```

看到 `Learning iteration xx/100` 在跳动 = **成功！**

---

## 第八步：正式训练 + 看曲线

```bash
# 正式训练（用 tmux 防断线）
tmux new -s train
python legged_lab/scripts/train.py --task=omni_walk --headless --num_envs=4096 --logger=tensorboard
# 按 Ctrl+B 然后按 D → 脱离 tmux，训练后台继续跑
```

看曲线（JupyterLab 里再开一个 Terminal）：
```bash
export CONDA_ENVS_PATH="/root/autodl-tmp/conda_envs"
eval "$(conda shell.bash hook)"
conda activate env_isaaclab
cd /root/autodl-tmp/TienKung-Lab
tensorboard --logdir=logs --host 0.0.0.0 --port 6006
```

然后：
1. 回到 **AutoDL 控制台** → 你的实例 → 点击 **「自定义服务」**
2. 会显示一个外网地址（如 `https://xxxxx.autodl.fun`）
3. 浏览器打开 → 看到训练曲线

---

## 遇到问题？

| 现象 | 解决 |
|------|------|
| `conda activate` 报错 | 先跑 `eval "$(conda shell.bash hook)"` |
| Vulkan / GPU 相关错误 | 跑 `bash setup_tienkung.sh` 会自动修复 |
| 训练报 `KeyError: omni_walk` | 跑 `cd /root/autodl-tmp/TienKung-Lab && python integrate_omni.py` |
| 显存不足 OOM | 把 `--num_envs=4096` 改成 `2048` 或 `1024` |
| 下载太慢 | AutoDL 快捷工具里开「学术加速」：`source /etc/network_turbo` |

---

## 完成后记得保存镜像！

环境跑通后：**AutoDL 控制台 → 实例 → 更多 → 保存镜像**

下次开新实例直接选「我的镜像」，跳过以上所有步骤。
