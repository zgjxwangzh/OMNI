## 详细步骤拆分

### 第一阶段：动作重定向（第一组负责）

> 目标：把人体动捕数据转换成 OMNI 机器人能用的参考动作文件

#### 步骤 1.1：理解数据格式

**输入**：BVH 文件（人体骨骼动画）
- 骨骼结构：Hips → 双腿 → 双脚、脊柱 → 双臂 → 双手
- 每帧数据：每个关节的 3 轴旋转角度 (Euler)

**输出**：TienKung-Lab 格式的 .txt 或 .npz 文件
- 每帧数据：OMNI 的 29 个关节角度 + 根节点位移 + 脚部接触标签

#### 步骤 1.2：建立骨骼映射表

需要定义人体骨骼和 OMNI 关节的对应关系：

```
人体骨骼              →  OMNI 关节
─────────────────────────────────────────
Hips (根节点)         →  base_link (6DOF 浮动基座)
RightUpLeg (Y/X/Z)   →  hip_roll_r / hip_pitch_r / hip_yaw_r
RightLeg             →  knee_pitch_r
RightFoot            →  ankle_roll_r / ankle_pitch_r
LeftUpLeg (Y/X/Z)    →  hip_roll_l / hip_pitch_l / hip_yaw_l
LeftLeg              →  knee_pitch_l
LeftFoot             →  ankle_roll_l / ankle_pitch_l
Spine/Spine1/Spine2  →  waist_yaw / waist_pitch / waist_roll
LeftShoulder + Arm   →  shoulder_pitch_l / shoulder_roll_l / shoulder_yaw_l / elbow_pitch_l / elbow_yaw_l / wrist_roll_l / wrist_pitch_l
RightShoulder + Arm  →  shoulder_pitch_r / shoulder_roll_r / shoulder_yaw_r / elbow_pitch_r / elbow_yaw_r / wrist_roll_r / wrist_pitch_r
Neck/Head            →  (OMNI nohead 版本无头，忽略)
```

#### 步骤 1.3：编写重定向脚本

核心逻辑：
1. 读取 BVH 每一帧的人体关节旋转
2. 通过骨骼映射 + 坐标系变换，转换为 OMNI 的关节角度
3. 处理左右手差异、坐标系差异（BVH 是 Y-up，Isaac Sim 是 Z-up）

#### 步骤 1.4：后处理

- **关节限位裁剪**：确保角度在 OMNI 电机范围内（查 joint_cfg.py）
- **脚部滑动修正**：脚着地时（通过高度判断），锁定脚的位置
- **数据平滑**：低通滤波（Butterworth 滤波器，截止频率 6-8Hz）去除抖动
- **接触标签**：根据脚的高度 + 速度，标记每帧哪只脚着地（0=空中, 1=着地）

#### 步骤 1.5：验证输出

- 在 PyBullet 或 Isaac Sim 中回放，确认动作看起来合理
- 检查关节角度是否都在限位内
- 检查脚部是否还有明显滑动

### 第二阶段：训练准备（第二组负责，可与第一阶段并行）

> 目标：搭建任务训练环境，等第一组数据好了直接开训

#### 步骤 2.1：设计任务配置

为每个比赛任务创建独立的配置文件：

```
legged_lab/envs/omni/
├── walk_cfg.py        ← 已有（基础走路）
├── climb_stairs_cfg.py ← 新建（爬楼梯）
├── flip_box_cfg.py     ← 新建（翻箱子）
├── high_jump_cfg.py    ← 新建（跳高）
└── hurdle_cfg.py       ← 新建（跨栏）
```

每个配置文件需要定义：
- 奖励函数（什么是"成功"）
- 场景配置（楼梯/箱子/栏杆的 3D 模型）
- 终止条件（摔倒了就重置）

#### 步骤 2.2：定义各任务的奖励函数

| 任务 | 关键奖励项 |
|------|-----------|
| 翻箱子 | 手碰到箱子 + 箱子翻转角度 + 身体不倒 |
| 跳高 | 重心最高点 + 过杆成功 + 落地稳定 |
| 跨栏 | 前进速度 + 不碰栏 + 身体不倒 |
| 爬楼梯 | 前进速度 + 上楼台阶数 + 身体不倒 |

#### 步骤 2.3：搭建仿真场景

在 Isaac Sim 中创建比赛场地：
- 导入障碍物 3D 模型（箱子、栏杆、楼梯台阶）
- 设置碰撞属性
- 随机化参数（箱子大小、栏杆高度等）提升鲁棒性

#### 步骤 2.4：在 __init__.py 中注册新任务

```python
task_registry.register("omni_climb_stairs", OMNIEnv, OMNIClimbStairsCfg(), OMNIAgentCfg())
task_registry.register("omni_flip_box", OMNIEnv, OMNIFlipBoxCfg(), OMNIAgentCfg())
task_registry.register("omni_high_jump", OMNIEnv, OMNIHighJumpCfg(), OMNIAgentCfg())
```

### 第三阶段：任务训练（等第一阶段数据就绪后）

> 目标：训出各任务的策略模型

#### 步骤 3.1：用动捕数据替换临时数据

```bash
# 把重定向后的数据放到 datasets 目录
cp retargeted_climb.npz legged_lab/envs/omni/datasets/climb.npz
cp retargeted_flip.npz legged_lab/envs/omni/datasets/flip.npz
```

#### 步骤 3.2：从走路策略微调（推荐）

```bash
# 爬楼梯：从 model_4900.pt 继续训练
python train.py --task=omni_climb_stairs --headless --num_envs=4096 \
    --load_run=2026-07-28_23-43-16 --checkpoint=model_4900.pt \
    --logger=tensorboard

# 翻箱子
python train.py --task=omni_flip_box --headless --num_envs=4096 \
    --load_run=2026-07-28_23-43-16 --checkpoint=model_4900.pt

# 跳高
python train.py --task=omni_high_jump --headless --num_envs=4096 \
    --load_run=2026-07-28_23-43-16 --checkpoint=model_4900.pt
```

每个任务预计额外训练 10000-30000 步（2-5 小时）。

#### 步骤 3.3：监控训练

- TensorBoard 看 reward 曲线
- 重点关注：episode_length（不摔倒）、任务完成度（箱子翻了吗、杆过了吗）

#### 步骤 3.4：保存最优模型

```
logs/
├── omni_walk/          ← 基础走路（已完成）
├── omni_climb_stairs/  ← 爬楼梯策略
├── omni_flip_box/      ← 翻箱策略
└── omni_high_jump/     ← 跳高策略
```
