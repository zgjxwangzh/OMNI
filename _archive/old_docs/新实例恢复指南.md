# 新实例恢复指南（基于镜像 + 共享存储）

> 适用场景：从已保存的镜像创建新实例，`/root/autodl-fs/` 已自动挂载
> 耗时：约 30-40 分钟（主要是 Isaac Sim 下载）
> 无需重新上传任何文件

---

## 前提条件

你之前已经做了这两件事：
1. **保存了镜像**（AutoDL 控制台 → 实例 → 更多 → 保存镜像）
2. **同步了文件到 autodl-fs**：
   ```
   /root/autodl-fs/omni_project/
   ├── TienKung-Lab/           ← 训练框架（含已集成的 OMNI）
   ├── omni_29dof_v260705/     ← OMNI 机器人模型
   └── IsaacLab.tar.gz         ← Isaac Lab 源码
   ```

---

## 操作步骤

### 第一步：创建新实例

1. AutoDL 控制台 → **创建实例**
2. GPU 选 **RTX 4090**
3. 镜像选 **「我的镜像」** → 选你之前保存的（如 `omni-tienkung-ready`）
4. 数据盘 50GB
5. 创建 → 等待开机

> 镜像里已包含：Vulkan 配置、系统库等（不用重新配）

### 第二步：打开终端

- 方式 A：JupyterLab → 左上角「+」→ Terminal
- 方式 B：SSH 登录

### 第三步：运行恢复脚本

```bash
# 把恢复脚本从共享存储复制到数据盘（如果之前同步了的话）
cp /root/autodl-fs/omni_project/omni_29dof_v260705/restore_new_instance.sh /root/autodl-tmp/

# 运行
cd /root/autodl-tmp
bash restore_new_instance.sh
```

> 如果 autodl-fs 里没有这个脚本，可以从 JupyterLab 重新上传。

### 第四步：等它跑完

看到以下输出就是成功：
```
============================================
  恢复完成！可以开始训练了
============================================
```

### 第五步：开始训练

```bash
export CONDA_ENVS_PATH="/root/autodl-tmp/conda_envs"
eval "$(conda shell.bash hook)"
conda activate env_isaaclab
cd /root/autodl-tmp/TienKung-Lab

# 用 tmux 防断线
tmux new -s train
python legged_lab/scripts/train.py --task=omni_walk --headless --num_envs=4096 --logger=tensorboard
```

## 一劳永逸：设置 .bashrc

恢复完成后执行一次，以后每次开终端自动激活环境：

```bash
cat >> ~/.bashrc << 'EOF'
export CONDA_ENVS_PATH="/root/autodl-tmp/conda_envs"
eval "$(conda shell.bash hook)"
conda activate env_isaaclab 2>/dev/null
EOF
source ~/.bashrc
```

## 文件存储说明

| 目录 | 关机 | 换实例 | 速度 | 放什么 |
|------|:---:|:---:|:---:|--------|
| `/`（系统盘） | 保留 | 随镜像 | 一般 | 系统配置 |
| `/root/autodl-tmp`（数据盘） | 保留 | **清空** | 快 | conda 环境、训练 |
| `/root/autodl-fs`（共享存储） | 保留 | **保留** | 一般 | 代码、模型、备份 |

**核心逻辑**：
- 代码和模型放 `autodl-fs`（永远不丢）
- conda 环境放 `autodl-tmp`（跑得快，丢了重装）
- 系统配置靠镜像（Vulkan 等）

---

## 训练产出同步（重要！）

训练完的 checkpoint 在数据盘，**换实例会丢**！训练结束后记得同步：

```bash
# 把训练结果同步到共享存储
cp -r /root/autodl-tmp/TienKung-Lab/logs /root/autodl-fs/omni_project/logs_backup/
```

或者训练时直接把日志写到 autodl-fs：
```bash
python legged_lab/scripts/train.py --task=omni_walk --headless --num_envs=4096 \
    --logger=tensorboard --logdir=/root/autodl-fs/omni_project/logs
```
