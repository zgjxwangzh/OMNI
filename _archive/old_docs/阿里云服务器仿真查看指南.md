## 三、查看仿真效果

### 基本命令格式
```bash
cd /mnt/workspace/TienKung-Lab
export DISPLAY=:1.0
/workspace/isaaclab/isaaclab.sh -p legged_lab/scripts/play.py --task=omni_walk --num_envs=1 \
    --load_run=<训练目录> --checkpoint=<模型文件> \
    --motion_file=<动作数据文件>
```

### 1. 基础走路模型（5 万步）
```bash
cd /mnt/workspace/TienKung-Lab
export DISPLAY=:1.0
/workspace/isaaclab/isaaclab.sh -p legged_lab/scripts/play.py --task=omni_walk --num_envs=1 \
    --load_run=2026-07-28_23-43-16 --checkpoint=model_4900.pt
```
- 默认使用 `walk.txt` 动作数据，无需加 `--motion_file`
- 效果：机器人在平地上走路（略有摇摆，5 万步尚未完全收敛）

### 2. 爬楼梯微调模型
```bash
cd /mnt/workspace/TienKung-Lab
export DISPLAY=:1.0
/workspace/isaaclab/isaaclab.sh -p legged_lab/scripts/play.py --task=omni_walk --num_envs=1 \
    --motion_file=上楼梯01_chr00.txt \
    --load_run=2026-08-08_11-41-45 --checkpoint=model_4800.pt
```
- ⚠️ **注意**：爬楼梯模型需要楼梯地形才能看到效果，当前场景是平地，机器人可能前倾但不走
- 这是正常的——模型在平地上"找不到楼梯"

### 3. 其他动作数据
可用 `--motion_file` 参数切换，无需修改配置文件：
```bash
--motion_file=跳高05_chr00.txt
--motion_file=翻箱子01_chr00.txt
--motion_file=跑步01_chr00.txt
```

完整动作数据列表：
```bash
ls legged_lab/envs/omni/datasets/motion_visualization/
```

## 五、停止仿真

在 JupyterLab 终端中按 **Ctrl+C** 即可退出正在运行的 Python 命令（如 play.py、train.py）。

如果 Ctrl+C 无效，可以新开一个终端执行：
```bash
pkill -f "play.py"
```

## 六、常见问题

### Q: 报错 `ModuleNotFoundError: No module named 'torch'`
**原因**：noVNC 桌面的终端 Python 路径被干扰。  
**解决**：在 **JupyterLab 的 Terminal** 里执行命令，不要在 noVNC 桌面的终端里跑。

### Q: 机器人一动不动
- 基础模型：等几秒，或按空格键确认仿真在运行
- 爬楼梯模型：平地上没有楼梯，机器人会前倾但不走（正常现象）

### Q: 机器人走出一摇一摆
5 万步基础模型尚未完全收敛，属于正常。继续训练到 10-20 万步会更稳。

### Q: 想看爬楼梯效果怎么办？
需要在 `play.py` 中修改地形配置，将 `terrain_type` 从 `"plane"` 改为楼梯地形。当前版本暂不支持，后续可开发。

## 七、训练新模型（进阶）

