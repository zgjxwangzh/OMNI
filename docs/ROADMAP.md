## 六、关键决策记录

| 决策 | 原因 | 影响 |
|------|------|------|
| 使用 omni_mimic 而非 xMimic | xMimic 是 dex_evt 机器人（22 关节），不匹配 OMNI（29 关节） | 训练框架正确 |
| 使用 DelayedDCMotor 而非 Implicit | 更接近真实硬件，利于 sim-to-real | 训练更慢但部署更容易 |
| 双机并行训练 | 节省时间，提高效率 | 跳高和跑步同时训练 |
| 拒绝 resume 旧模型 | 避免行为锚定，从头训练更干净 | 训练时间更长但质量更好 |
| 阿里云也用于训练 | 原来只用于可视化，现在训练框架跑通了 | 双倍训练产能 |
